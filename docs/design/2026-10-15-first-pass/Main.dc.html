Getting the most out of agents Before you start

What you are doing here

This course is about working with an AI agent. To show it, we follow one job from start to finish.

Two things are on screen at once, so here they are, apart.

You

You answer the agent's questions, decide what done means, set up the checks, and judge what comes back. That is the work this course teaches.

The agent

A scripted one, nothing real. It does the building, inside a box you put round it. It will also, at times, guess, over-build and mark its own homework, so you can see it happen.

The fridge activity

The job we follow: a drag-and-drop activity for a client's food-hygiene course, built in code because the authoring tool can't do it. It is only the example. You never build it yourself.

01

The subject is the agent. What works and what doesn't when you ask one to build something, and the walls that keep it honest: things written down, done defined, tests that must pass, other agents checking its work, evidence you can judge.

02

The fridge is the example. Every module picks the job up where the last one left it, from a vague ask in module 00 to a finished piece you decide whether to accept in module 05.

03

You do your part at each step. Short interactions with the agent, then a check with feedback, then one takeaway. Eight modules, about 50 minutes. Leave after any module and come back.
