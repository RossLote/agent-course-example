## Agent: round 1

- Research: the xAPI spec says an LRS must accept any version header starting
  with "1.0.", so pinning the client to 1.0.2 is valid everywhere. The classic
  launch passes endpoint, auth and actor (and activity_id, registration) in the
  query string, from a zip with `tincan.xml` at the root; cmi5 launches
  differently. xAPI.js (`@xapi/xapi`, TypeScript) has a version option, a
  launch-data helper and a fetch adapter; TinCanJS does the same, older.
- Five questions, ranked, each with a recommendation:
  1. Launch and package: TinCan launch and a tincan.xml zip, header 1.0.2
     (recommended); confirm the LMS imports such a zip, and whether an LRS
     endpoint is available to test against.
  2. Statements for the LMS: `completed` with completion and a scaled score
     on the course activity (recommended); does the LMS need `passed`?
  3. Library: `@xapi/xapi` with the fetch adapter, version 1.0.2, behind a
     small Tracker interface so the fake record store swaps in (recommended);
     a non-blocking queue with one retry.
  4. Authoring format: one YAML file per module, schema-checked at build time
     (recommended), over Markdown or JSON.
  5. Resume: the xAPI State API with a localStorage fallback (recommended).

## Agent: the launch read, the brief closed

- The URL is the classic TinCan launch, which settles question 1. What it
  adds: the auth value is a custom scheme, `tincan <token> <registration>`,
  to be sent verbatim as the Authorization header, not Basic; the actor is
  an account-based agent to be used verbatim; registration and activity_id
  are supplied. The record store answers with `WWW-Authenticate: tincan`
  and CORS open to every origin, so the course can call it directly; it has
  no `/about` resource, so the version cannot be discovered and the header
  is simply 1.0.2. The extra Spark parameters name a postMessage bridge to
  the LMS frame; the module's own files sit behind an authenticating
  CloudFront, so how Evolve uses it could not be read. Direct calls do the
  job, so the bridge is a later round.
