# 07 · Put it together

**Wall:** all of them. **Time:** about 6 minutes. The capstone: scored.

**Objective.** The learner can lay out the loop for a new request and, for each thing that
goes wrong, name the wall that handles it.

## Screen 1 · A new request

> Round two's brief is done: a hint after two wrong drops (D9), eggs in the salad drawer
> (D10). You are setting up the work. Lay it out.

## Screen 2 · Order the loop

Eight cards to drag into order (keyboard: pick up with Enter, move with arrows, drop with
Enter):

1. Brief: the agent asks, you decide, D9 and D10 on the record.
2. Epic: the pieces, each with acceptance, and the demo script.
3. Epic review: gaps found while they cost a sentence.
4. Build: workers in their boxes, gate green.
5. Simplify, review, adversarial review: agents checking agents.
6. Walkthrough and pull request: the evidence, written for you.
7. You judge it: door, undo, evidence against the acceptance.
8. Retro, over several runs: what repeats, what to change.

Scored: one point per card in its place. Feedback shows the right order with a line on any
card that was out of place (*"The epic review comes before the build; a gap found during the
build is a rebuild."*).

## Screen 3 · Name the wall

Six things that go wrong. For each, pick the wall.

| What went wrong | Wall |
|---|---|
| The builder added a "hint streak" counter nobody asked for. | **The record.** A gap in the brief was filled with a guess. |
| The builder says the hint is done, and you cannot say whether it is. | **Done.** No acceptance a reviewer can see. |
| While adding the hint it changed the score screen's wording too. | **The gate.** Its files were not limited, or the change was not rejected. |
| The gate is green, and the hint code is a copy of the message code with one word changed. | **Other agents.** Simplify's reuse question. |
| It is nine in the morning and there is a forty-file change waiting. | **Evidence.** Door, undo, walkthrough against the demo script. |
| A colleague found that the hint shows after two wrong drops *of the same item*, which nobody specified and no check questioned. | **The arrow.** Which check would have caught it; does it repeat; change the check. |

Scored: one point each. Feedback per row.

## Screen 4 · Your score, and the box

The score out of fourteen, with the box drawn whole: the record, done, the gate, other
agents, evidence, and the arrow round it. One line: *That is the whole workflow. Everything
else is detail.*

## Screen 5 · Try this tomorrow

Not assessed. Four cards for any agent, including the chat tools you already use:

1. **Before you ask for anything, ask it to ask you five questions first.** Answer in a
   paragraph. Watch how much of what it would have guessed you had an opinion on.
2. **Write done before it starts.** Three things you will do and see when it is finished.
   Give it those, not adjectives.
3. **When it says done, open a new chat and ask a fresh agent what is wrong with it.** Make
   it say where. Do not let it say "looks fine".
4. **Ask for the evidence, not the explanation.** "Show me it doing step 2" beats "tell me
   it works".
